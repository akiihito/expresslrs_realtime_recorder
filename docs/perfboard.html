ユニバーサル基板 — 配置＆配線

検証済みの回路（KiCad版と同一のネットリスト）を 2.54mm ピッチの マス目に落としたもの。配線リストはネットリストから機械生成しているので漏れが無い。

必要な基板: 35 × 26 穴以上（穴の範囲で約 86 × 64 mm）
95×72mm クラスの片面ユニバーサル基板でぎりぎり収まる。買う前に実物の穴数を数えること （縁の余白のぶん、カタログ寸法より穴数が少ない。95×72mmでも30×25穴しかない製品が実在する）。 余裕を見るなら 100×75mm 以上。具体的な商品と、基板以外に買うものは hardware/README.md の「部品」にまとめてある。 座標は (列, 行) で、左上が (1,1)。
⚠️ 通電前に必ず確認（Pico即死を防ぐ3点）
  1. 降圧モジュールは繋ぐ前に単体で5.0Vへ調整。可変品は初期12V等のことがある。
  2. +5V と VBAT(7〜13V) を絶対に接触させない。テスターの導通モードで (28,5)（OUT+ = +5V）と (35,5)（IN+ = VBAT）の間が 導通しないことを確認（降圧モジュール未接続時）。
  3. 給電は VBUS (27,3) のみ。VSYS (27,4) には入れない （内部D1でUSBに5Vが回らずゲームパッドに給電できない）。
  4. J3.1 → F1.2 の線（ヒューズより前）は最短で引き、VBATの線と束ねない。 ここだけはヒューズに守られていないので、短絡するとF1が意味を失う。

一番下の行（電源）の並び

行26は左から右へ (10,26) J3(LiPo+) → (12,26) F1 (16,26) → C1 → C2 と、 電流の向きどおりに並べてある。C1/C2の＋が左を向いているのはこのため。

J3とF1は必ず隣どうしに置く。この2つの間だけはヒューズに守られていないので、 離すと無保護なLiPo+が基板を横断することになる。現状は (10,26) から (12,26) まで 5mm。

裏面の配線について — 確認済みのことと、していないこと

確認済み（生成のたびに機械で検査）
  • ネットリストの全ピンに穴が割り当たっている（漏れたら図を作らない）
  • 同じ穴を2つの部品が使っていない
  • 裸のGND母線が、別ネットのピンを貫通していない
  • どの配線区間を裸線で引けるか — 別ネットのピンを踏まないか、裸のGND母線と 交差しないか、ヒューズ前のLiPo+でないかを1区間ずつ見る（配線リストの「線」列）
していないこと
  • 1本ずつの引き回しは決めていない（下の配線リストの28本）。 裏面で実際にどう這わせるかは組む人の裁量。ただしどの区間を裸線で引けるかは検査している （配線リストの「線」列）。
  • 実物の部品での現物合わせ（J2とF1は実測していない）

配線のやり方

片面ユニバーサル基板の前提。部品は表に挿し、配線は全部裏（はんだ面）。

用途使うもの理由
GND母線すずメッキ線 φ0.6 太く低抵抗。直線で引ければ交差しないので裸線でよい
電源 (+5V / VBAT / LiPo+)AWG24程度 電流が流れるので細い線は不可。被覆が要るかは別の話で、 区間ごとに配線リストの「線」列を見る
信号UEW(ポリウレタン線) φ0.3 本数が多く交差する。はんだの熱で被覆が溶けるので皮むきが要らない。 細いので重ねられる
隣接する穴どうし部品の足 切り落とさず曲げて隣へ渡す。線が減る
足を使える箇所（隣の穴なので線が要らない。5本）: D1.2(3,16)-R1.2(4,16) / D2.2(3,18)-R2.2(4,18) / D3.2(3,20)-R3.2(4,20) / D4.2(3,22)-R4.2(4,22) / D5.2(3,24)-R5.2(4,24)
はんだブリッジで長い距離を繋がない。隣の穴どうしなら可だが、何穴も盛って繋ぐのは 後で剥がれる・短絡する。素直に線を使う。

配線リスト（GND以外）

同じネットの穴どうしを繋ぐ。1区間が1本で全28本 （裸 8本 / 裸可 2本 / 被覆 18本）。繋ぐ順は電気的には問わないので、下の順に読まなくてよい。

「材」列 — 何で引くか（部品の足 5本 / すずメッキ φ0.6 5本 / UEW φ0.29 13本 / AWG24 5本）
  • 部品の足 — 隣の穴なので線が要らない。切らずに曲げて渡す
  • すずメッキ φ0.6 — 裸線でよい区間。抵抗の切った足でも代用できる （ただし母線のような長い距離は足では届かない）
  • UEW φ0.29 — 絶縁が要る信号。ポリウレタン銅線。 はんだの熱で被膜が溶けるので皮むきが要らず、細いので交差を重ねられる
  • AWG24 — 絶縁が要る電源（+5V・Net-(J3-Pin_1)・VBAT_7_13V）。 ここをUEWにしてはいけない — 電流が流れる
「材」は2つの軸の掛け算です。絶縁が要るか（右の「絶縁」列）と 太さが要るか（電流が流れるネットか）は別の話で、 たとえば +5V は電流が流れるが裸でよい区間があり、そこは太い裸線になります。 逆に信号で絶縁が要る区間を AWG24 にするのは電気的には問題ないものの、 13本が Picoの左列に集まるので裏面が厚くなって入りません。
「絶縁」列の意味
  • 裸 — 交差も踏むピンも無い
  • 裸可 — 他の配線と交差するだけ。交差は片方が被覆なら足りるので、 相手を被覆にするなら裸でよい
  • 被覆 — 裸では短絡する
判定の根拠: 直線で引いた時に ①別ネットのピンを踏む ②裸のGND母線と交差する ③ヒューズより前のLiPo+、のどれかに当たれば「被覆」。 ①の区間は踏むピンを避けられる順に読み替えれば裸にできることがある （例: C1.1 → C2.1 → F1.1 ではなく F1.1 → C1.1 から繋ぐと、この1本は裸でよくなる）。

組み立て順

  1. ヘッダから。Picoの2×20メスヘッダを (20,3)-(20,22) と (27,3)-(27,22) に。 USB側を行1（上端）に向ける。7穴間隔（17.78mm）であることを挿す前に確認。
  2. GNDバスを張る（上記）。後からだと部品が邪魔になる。
  3. 背の低い順に: 抵抗 → ダイオード/LED → IC無し → コンデンサ → スイッチ → コネクタ → ヒューズホルダ。
  4. 各ネットを配線したら、テスターの導通モードで配線リストを1行ずつ潰す。 通電前にここで潰すのが一番安い。
  5. 通電前に J3の極性と +5VとVBATが短絡していないことをテスターで確認。
  6. 降圧モジュールは繋ぐ前に単体で5.0Vに調整してから接続する。

部品ごとの注意

定数・寸法・購入情報は hardware/README.md の「部品」が正本。 ここは手組み固有の落とし穴だけ。

  • J2 降圧モジュール(MP1584EN): 穴の左右間隔が18.9mmで 2.54mmの倍数にならない（7.44穴ぶん）。基板に直接挿さらないので、 リード線で配線するか、片側だけピンヘッダで固定して反対側を線で繋ぐ。 図の枠は設置スペースの目安。
  • F1 ヒューズホルダは基板に挿さらない。基板取付品はどちらも 足が太く、ピッチも2.54mmの倍数でない — ミニ平型 118222 は φ1.78mm・9.92×3.4mm、 ミゼットのクリップ 110521(FUC-03A) は φ1.7mm・足間6.7mm。 ユニバーサル基板の穴(φ約1mm)には入らない。
    手組みでは配線用（インライン）ヒューズホルダを使い、LiPo+ の線に割り込ませるのが素直。 ヒューズ交換もしやすく、挿抜の力が基板にかからない。この場合F1は基板に載らないので (12,26) と (16,26) を直結する（図のF1枠は使わない）。
    基板上に置きたい場合は、J2と同じくリード線で (12,26) と (16,26) に繋ぎ、 本体は接着（ホットボンド／両面テープ）か結束バンドで固定する。ヒューズを挿す力が かかるのではんだだけで支えないこと。買う基板は図の 35×26 穴より 大きいので、本体は行26より下へはみ出してよい — 基板の端なので指が入り、 ヒューズを抜き差しできる。
  • ⚠️ 基板中央（列11-19×行11-25）が一番広いが、そこにF1を置かないこと。 Picoの左列から左へ出る配線が13本通る帯で、ここにLiPo+(7〜13V)の太線を2本 横断させることになる。擦れて信号線と短絡すると12VがGPIOに乗ってPicoが死ぬ。 電源は下端と右側にまとめ、信号の帯と交わらせない。
  • タクトスイッチ(SW1/SW2)は4本足のうち「対角の2本」だけを使う。 SW1は (7,6) と (10,8)、SW2は (7,12) と (10,14)。残り2本は挿さない（切るか、穴の無い所へ逃がす）。
    4本足は2本ずつが内部で繋がって1つの端子になっていて、押すとその2組の間が繋がる。 同じ組の2本を選ぶと、押しても押さなくても導通したまま＝常時押されている状態になる。 対角なら、どちらの向きで組になっていても必ず別々の端子を掴むので安全。
  • ⚠️ 挿す前にテスターで確かめる。選んだ2本が、離した状態で導通せず、 押すと導通すること。これだけは部品の個体差に関係なく確実。
    足間は6.5×4.5mmで2.54mmの倍数でないので、7.62×5.08mm（3穴×2穴）に広げて挿す。 6.5mmを7.62mmへ広げる方が、5.08mmへ狭めるより足への負担が小さい。
  • LED(D1〜D5)は極性あり。長い足がアノード(A)で、図では右側の穴 （抵抗に近い方）。短い足＝胴の平らな側が左でGND。
  • 電解コン C1/C3 も極性あり。どちらの穴が＋かは下の 「コンデンサの向き」の表に出してある。
  • D6 TVSは双方向品なので極性不問。
  • コンデンサは2個1組で、容量違いを並列に入れている（図で横並びなのはこのため）。 C1(470µF)/C3(100µF)は蓄え — 送信バーストや突入電流でレールが落ちるのを支える、 ミリ秒の仕事。C2/C4(100nF)は高周波の逃がし。電解コンはESR/ESLが大きく 高周波では効かないので、セラミックを並べる。
  • ⚠️ 100nF(C2/C4)に効くのは「太い線」ではなく「短い線」。効きを決めるのは 配線のループインダクタンスで、ほぼ長さに比例する（太さはほとんど効かない）。 現状 C2→J1.3 が約107mm、C4→U1.40 が約36mm。この長さだと10MHz付近で 配線のインピーダンスが100nF自身の数十倍になり、ほぼ効かない。 このまま行くと決めた（2026-11-03）。動かすのは、組んでから症状が出た時でよい （CRSFのエラー増、ゲームパッド挿抜でのリセット、電源まわりのノイズ）。 その時は C2をJ1の隣、C4をU1.40の隣へ動かす（GND側の戻りも一緒に短くする）。 C1/C3は蓄えが仕事なので、この距離でも実害は無い。
  • R6(680Ω)はGP0とNano TXの間に必ず直列で入れる。半二重バスの衝突保護。

J2（降圧モジュール）の向き

⚠️ ここを逆にするとPicoが即死する。OUT側に12Vを入れると、インダクタと ハイサイドの寄生ダイオードを通ってIN側にほぼ12Vが出る。そのINにPicoを繋いでいるので、 VBUSに12Vが乗る（絶対最大5.5V）。

⚠️ これは「180°回した向き」であって鏡像ではない。 KiCadのフットプリントは INが左・−が上、この図は OUTが左・＋が上 で、 水平に180°回すとこうなる（左右だけでなく上下も入れ替わる）。OUTを左にしてあるのは Picoと+5V系が左にあって線が短くなるため。
鏡像にはできない。左右だけ入れ替えるには部品を裏返すしかなく、そうすると 実装面（コイル・IC・半固定抵抗のある面）が基板側を向いて、5.0Vへの調整が できなくなる。実装面は上に向けたまま、水平に180°回すこと。
最終的な判断はモジュール本体のシルク（IN+ / IN− / OUT+ / OUT−）で行う。 図は配線先を示しているだけ。

通電前の確認: 降圧モジュールを外した状態で、 (28,5)（+5V）と (35,5)（VBAT）の間がテスターで 導通しないこと。ここが繋がっていたら、どこかで+5VとVBATが短絡している。
