ユニバーサル基板 — 配置＆配線

検証済みの回路（KiCad版と同一のネットリスト）を 2.54mm ピッチの マス目に落としたもの。配線リストはネットリストから機械生成しているので漏れが無い。

必要な基板: 35 × 26 穴以上（穴の範囲で約 86 × 64 mm）
95×72mm クラスの片面ユニバーサル基板でぎりぎり収まる。買う前に実物の穴数を数えること （縁の余白のぶん、カタログ寸法より穴数が少ない）。余裕を見るなら 100×75mm 以上。 座標は (列, 行) で、左上が (1,1)。
⚠️ 通電前に必ず確認（Pico即死を防ぐ3点）
  1. 降圧モジュールは繋ぐ前に単体で5.0Vへ調整。可変品は初期12V等のことがある。
  2. +5V と VBAT(7〜13V) を絶対に接触させない。テスターの導通モードで (28,9) と (35,9) の間が導通しないことを確認（降圧モジュール未接続時）。
  3. 給電は VBUS (27,3) のみ。VSYS (27,4) には入れない （内部D1でUSBに5Vが回らずゲームパッドに給電できない）。

配線のやり方

片面ユニバーサル基板の前提。部品は表に挿し、配線は全部裏（はんだ面）。

用途使うもの理由
GND母線すずメッキ線 φ0.6 太く低抵抗。直線で引ければ交差しないので裸線でよい
電源 (+5V / VBAT)被覆線 AWG24程度 電流が流れる。交差するので被覆必須
信号被覆線 AWG26〜30 / UEW(ポリウレタン線) 本数が多く交差する。UEWなら細くて取り回しが楽
隣接する穴どうし部品の足 切り落とさず曲げて隣へ渡す。線が減る
足を使える箇所（隣の穴なので線が要らない）: LEDのアノードと抵抗の足 — D1(3,16)-R1(4,16) / D2(3,18)-R2(4,18) / D3(3,20)-R3(4,20) / D4(3,22)-R4(4,22) / D5(3,24)-R5(4,24)
はんだブリッジで長い距離を繋がない。隣の穴どうしなら可だが、何穴も盛って繋ぐのは 後で剥がれる・短絡する。素直に線を使う。

GND（25点）

1本ずつ配線せず、GNDバスを張る。 錫メッキ線（φ0.6mm程度）を裏面に 渡して母線にし、各GND点から最短で落とす。母線は 列19の縦（Picoの左隣）と行25の横（電源部）の2本を 交差点で繋ぐと全域に届く。

組み立て順

  1. ヘッダから。Picoの2×20メスヘッダを (20,3)-(20,22) と (27,3)-(27,22) に。 USB側を行1（上端）に向ける。7穴間隔（17.78mm）であることを挿す前に確認。
  2. GNDバスを張る（上記）。後からだと部品が邪魔になる。
  3. 背の低い順に: 抵抗 → ダイオード/LED → IC無し → コンデンサ → スイッチ → コネクタ → ヒューズホルダ。
  4. 各ネットを配線したら、テスターの導通モードで配線リストを1行ずつ潰す。 通電前にここで潰すのが一番安い。
  5. 通電前に J3の極性と +5VとVBATが短絡していないことをテスターで確認。
  6. 降圧モジュールは繋ぐ前に単体で5.0Vに調整してから接続する。

部品ごとの注意

  • J2 降圧モジュール(MP1584EN): 穴の左右間隔が18.9mmで 2.54mmの倍数にならない（7.44穴ぶん）。基板に直接挿さらないので、 リード線で配線するか、片側だけピンヘッダで固定して反対側を線で繋ぐ。 図の枠は設置スペースの目安。
  • タクトスイッチ(SW1/SW2): ブレッドボードで使っているものをそのまま使う （2.54mmピッチに入る足のもの）。対角の2本を使うこと。同じ側の2本は 内部で繋がっていて、押しても切り替わらない。
  • LED(D1〜D5)と電解コン(C1/C3)は極性あり。LEDは長い足がアノード(A)、 図では右側の穴。
  • D6 TVSは双方向品なので極性不問。
  • C1/C2はJ1(Nano TX)の近く、C3/C4はPicoのVBUS近くが理想だが、 ユニバーサル基板では配線が長くなるのは避けられない。せめて 太めの線（φ0.6mm以上）で繋ぐ。
  • R6(680Ω)はGP0とNano TXの間に必ず直列で入れる。半二重バスの衝突保護。
