ゲームパッド F310 — GENERIC プロファイル

操作チャンネル動作
右スティック ←→CH1 Rollロール
右スティック ↑↓CH2 Pitchピッチ
左スティック ↑↓CH3 Throttle中央 = ホバリング推力。下端=最小 / 上端=最大。手を離すとホバリング値に戻る
左スティック ←→CH4 Yawヨー
D-pad ↑ / ↓—ホバリング推力トリム ±1%（飛行中の電圧降下を補正）
ACH7 / AUX3Arm トグル（1回=Arm、もう1回=Disarm）
BCH8 / AUX4未割当
XCH9 / AUX5未割当
YCH10 / AUX6未割当
LB / RBCH11,12 / AUX7,8未割当

CH5/CH6（AUX1/AUX2）はトリガー用だが F310 の L2/R2 はデジタルのため常に中央値。CH13〜16 は未使用（中央値）。

⚠️ Arm はスロットルスティックを下に押さえたまま行う 中央がホバリング推力（約1200us）なので、中央のままだと Betaflight がスロットル高として Arm を拒否する（ビープで通知）。
手順: ①スロットルを下に押さえる → ②A を押して Arm → ③ゆっくり離すとホバリングまで上がって離陸

LiteRadio 3 — LITERADIO プロファイル

操作チャンネル実測値（左右端）
右スティック ←→CH1 Roll172 / 1811
右スティック ↑↓CH2 Pitch182 / 1803
左スティック ↑↓CH3 Throttle172 / 1811（絶対値・位置保持）
左スティック ←→CH4 Yaw172 / 1811
送信機スイッチCH7〜CH12ボタンとして届く
⚠️ LiteRadio 3 使用時は必ず GP6 で LITERADIO に切り替える GENERIC のままだとゲームパッド解釈になり軸がバラバラになる。
⚠️ スロットルのジンバルは位置を保持する（自動で下がらない）。Arm 前に必ず一番下にあることを目視確認する。

PC からの操作手順

ファームウェア書き込み

  1. ゲームパッド（または LiteRadio）と外部5V を外す
  2. BOOTSEL を押しながら Pico を PC へ micro-USB 接続 →「RPI-RP2」がマウント
  3. ./scripts/flash.sh
  4. 配線を元に戻す

シリアルモニター

  • ./scripts/monitor.sh 115200 ※手持ちのFTDI変換器は分周器バグでボーレートが8倍ずれる。実際の線上は921600bps
  • 終了: Ctrl+A → K → y （Ctrl+A→D はデタッチでポートを掴んだままになるので注意）
  • リアルタイム表示: python3 scripts/live_view.py
⚠️ Betaflight Configurator 接続中は Arm できない MSP / CLI フラグによる安全機構でビープ拒否される。Arm の確認は USB を抜いてから行う。
